Proyecto 01

Sistema de
planillas automáticas

Automatización de asistencia

El área de RRHH de una cooperativa de barrido urbano gestionaba la asistencia de decenas de agentes usando hojas de cálculo dispersas. El proceso era manual, lento y propenso a errores. Construí un sistema de seis etapas que descarga automáticamente las planillas desde Google Drive, las valida, las convierte a PDF con la lógica correcta según el tipo de agente, las une y las manda a imprimir en una impresora de red Kyocera.

El sistema detecta el tipo de planilla leyendo una celda de control (L1) y aplica reglas distintas para agentes normales, municipales, coordinadores NOVAR y sin variaciones. La interfaz corre en PyQt6 con workers en QThread para no bloquear la UI.

Python PyQt6 Google Drive API OAuth 2.0 pypdf python-calamine QThread

Proyecto 02

App de stock
en red local

Gestión de depósito

Anteriormente, el Stock de los insumos de la organización se manejaba desde el entorno de Google Sheets. Con el correr del tiempo, el sistema necesitó automatizaciones para seguir evolucionando, por lo que se me ocurrió construir un Servidor Local que se encuentre funcionando 24/7 para implementar nuevas funciones como, por ejemplo, proyecciones de entregas, división de los insumos con un mapa organizativo, exportaciones e impresiones en diferentes formatos al PDF tradicional.

Incluye registro de ingresos y egresos, un módulo de tandas para agrupar egresos por lote, una pestaña de proyección hipotética de entregas y exportación a CSV. Fue entregada como ZIP listo para ejecutar.

Python Flask SQLite HTML / CSS / JS Red local LAN CSV Export

Proyecto 03

Mapa interactivo
de zonas de barrido

Visualización operativa

La supervisión de 30 zonas de barrido urbano se hacía con papel y llamadas. Construí un mapa SVG interactivo alojado como HTML estático que consume datos en tiempo real desde Google Sheets a través de un middleware propio en Google Apps Script. Cada zona refleja el estado actual del servicio con un click.

El sistema permite exportar el estado de cada punto a PDF usando jsPDF directamente desde el navegador, sin servidor externo. Treinta zonas agrupadas en puntos nombrados, actualizadas sin recargar la página.

JavaScript SVG Google Apps Script Google Sheets API jsPDF HTML estático
